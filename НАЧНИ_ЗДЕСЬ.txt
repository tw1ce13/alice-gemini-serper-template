НАЧНИ ЗДЕСЬ — навык Яндекс Алисы с Gemini

ВАЖНО: если этот проект уже лежит на GitHub, проще нажать Fork и подключить свою копию к Vercel. ZIP скачивать необязательно.

Если скачали ZIP:
1. Распакуйте архив двойным кликом.
2. На GitHub нажмите + → New repository и создайте репозиторий.
3. В пустом репозитории выберите Add file → Upload files.
4. Перетащите содержимое распакованной папки. Обязательно сохраните папку api и файл api/index.js внутри неё.
5. Нажмите Commit changes.
6. Войдите на vercel.com, нажмите Add New… → Project и импортируйте свой репозиторий.
7. В Vercel откройте Project → Settings → Environment Variables и добавьте:
   GEMINI_API_KEY — ключ Google AI Studio.
   SERPER_API_KEY — ключ Serper.
   Для обеих переменных выберите Production.
8. После сохранения переменных откройте Deployments, сделайте Redeploy и дождитесь статуса Ready.
9. Откройте Settings → Domains, скопируйте свой домен Vercel, добавьте /api и вставьте полный адрес в поле Webhook URL в настройках навыка Яндекс Диалогов.
10. В Основные настройки → Хранилище выберите «Использовать хранилище данных в навыке» — тогда навык будет помнить разговор и возвращающихся пользователей.

ЧТО НАВЫК ЗАПОМИНАЕТ

После включения хранилища:
- внутри разговора навык помнит последние реплики и понимает уточнения вроде «а на выходных?»;
- между разговорами помнит имя, число разговоров и несколько недавних тем. На колонке без входа в Яндекс ID память привязана к устройству, а для аккаунта Яндекс ID переносится между колонкой, телефоном и браузером.

Попробуйте голосом:
- «меня зовут Никита» — при следующем запуске навык поздоровается по имени;
- «забудь всё» — навык сотрёт сохранённые данные;
- «хватит» или «пока» — навык корректно завершит работу.

Если ошибка сервера появляется только при включённом хранилище, значит навык вернул объект состояния больше 1 КБ — это ограничение Яндекса. В шаблоне размер уже контролируется, поэтому проверьте, что развёрнута последняя версия кода (Deployments → Redeploy).

КАК ПРОВЕРИТЬ БЕЗ ПРОГРАММИРОВАНИЯ

1. В настройках навыка выберите тип доступа Приватный и сделайте навык доступным для тестирования.
2. На колонке или в приложении с Алисой войдите в тот же аккаунт Яндекса, который используете для консоли разработчика.
3. Скажите: «Алиса, запусти навык [название или активационное имя навыка]».
4. Задайте вопрос и проверьте, отвечает ли Алиса.

Если навык не запускается голосом или ещё не доступен для такого запуска, откройте Яндекс Диалоги → ваш навык → Тестирование. Там можно проверить ответ ещё до голосового запуска.

Если навык не отвечает, сначала проверьте Webhook URL, переменные в Vercel и то, что после изменения ключей был выполнен Redeploy. Не отправляйте API-ключи в чат и не загружайте их в GitHub.

Node.js устанавливать не нужно: он нужен только для дополнительной проверки кода, а не для обычного тестирования голосом.
